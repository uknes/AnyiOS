# Apple technology discovery catalog

Research date: 2026-10-09. Source: [Apple technology index](https://developer.apple.com/documentation/technologies).

**Unassessed discovery entries, not compatibility claims.** Apple’s index covers multiple platforms, web/server services, tools and release notes. Each entry needs an iOS/iPadOS availability and version audit before becoming a concrete runtime requirement. No entry is counted as an implemented API or verified gate. Older, private and third-party dependencies require separate binary-led discovery.
